# ربات اطلاع‌رسانی تلگرام

ربات تلگرام سریع‌ترین کانال ارتباط با مشتری است. برخلاف ایمیل که ممکن است در اسپم بیفتد و پیامک که هزینه دارد، تلگرام رایگان، فوری و دوطرفه است.

---

## چه کاری انجام می‌دهد

**اعلان‌های خودکار**

- هشدار قبل از اتمام اعتبار (بر اساس ساعتی که خود کاربر تعیین کرده)
- اطلاع لحظه‌ای از قطعی سرور و بازگشت آن
- تعلیق، تمدید، کسر هزینه و شارژ کیف پول
- پاسخ تیکت پشتیبانی
- هشدار مصرف ترافیک و عبور از سقف بودجه

**دستورهای دوطرفه**

| دستور | کار |
|---|---|
| `/start <کد>` | اتصال حساب پنل به تلگرام |
| `/balance` | موجودی کیف پول و اینکه تا کی کافی است |
| `/servers` | فهرست سرورها با وضعیت |
| `/server <نام>` | جزئیات سرور به همراه دکمه‌های کنترل |
| `/status` | وضعیت کلی حساب |
| `/mute` و `/unmute` | قطع و وصل موقت اعلان‌ها |
| `/unlink` | قطع اتصال |
| `/help` | راهنما |

**کنترل سرور با دکمه**

با دستور `/server` دکمه‌های روشن کردن، خاموش کردن و راه‌اندازی مجدد نمایش داده می‌شود. عملیات پرخطر مرحله تایید دارد و همه‌چیز در دفتر ممیزی با برچسب `via: telegram` ثبت می‌شود.

---

## راه‌اندازی

### ۱. ساخت ربات

در تلگرام به [@BotFather](https://t.me/BotFather) پیام دهید:

```
/newbot
```

نام و نام کاربری ربات را وارد کنید. توکنی که می‌دهد را کپی کنید.

### ۲. تنظیم توکن

در فایل `.env`:

```bash
TELEGRAM_BOT_TOKEN=123456789:AAE...توکنی-که-گرفتید
```

سپس اپلیکیشن و ورکر را دوباره راه‌اندازی کنید.

### ۳. بررسی اتصال

```bash
npm run telegram
```

اگر همه چیز درست باشد، نام کاربری ربات و وضعیت را نشان می‌دهد.

### ۴. ثبت دستورها در BotFather

خروجی دستور بالا یک فهرست دستور می‌دهد. در BotFather بزنید `/setcommands`، ربات را انتخاب کنید و آن فهرست را بفرستید. با این کار کاربران هنگام تایپ `/` منوی دستورها را می‌بینند.

## دو روش دریافت پیام

### long polling (پیش‌فرض)

ورکر دائماً از تلگرام پیام‌های جدید را می‌گیرد. نیازی به دامنه، SSL یا IP ثابت ندارد و برای اکثر نصب‌ها بهترین گزینه است.

```bash
npm run worker
```

در لاگ ورکر باید ببینید:

```
🤖 ربات تلگرام در حال دریافت پیام است.
```

### webhook

تلگرام پیام‌ها را به آدرس شما ارسال می‌کند. کمی سریع‌تر است ولی نیاز به دامنه با HTTPS معتبر دارد.

```bash
# ساخت توکن محرمانه
node -e "console.log(require('crypto').randomBytes(24).toString('hex'))"
```

مقدار را در `.env` بگذارید:

```bash
TELEGRAM_WEBHOOK_SECRET=توکنی-که-ساختید
```

سپس:

```bash
npm run telegram -- --webhook
```

برای برگشت به حالت قبل:

```bash
npm run telegram -- --polling
```

> هرگز هر دو حالت را همزمان فعال نکنید؛ پیام‌ها دو بار پردازش می‌شوند.

## اگر تلگرام از سرور شما در دسترس نیست

سرورهای داخل ایران معمولاً به `api.telegram.org` دسترسی مستقیم ندارند. دو راه دارید:

**الف) سرور را بیرون از ایران بگذارید.** ساده‌ترین راه، چون خود پنل هم باید به API هتزنر وصل شود.

**ب) از پروکسی استفاده کنید.** آدرس پروکسی خود را در `.env` بگذارید:

```bash
TELEGRAM_API_URL=https://your-telegram-proxy.example.com
```

پروکسی باید مسیر `/bot<token>/<method>` را دقیقاً به `api.telegram.org` منتقل کند. یک نمونه Nginx:

```nginx
location / {
    proxy_pass https://api.telegram.org;
    proxy_set_header Host api.telegram.org;
    proxy_ssl_server_name on;
}
```

## نحوه اتصال کاربر

۱. کاربر به `/dashboard/notifications-settings` می‌رود
۲. روی «اتصال به ربات تلگرام» می‌زند
۳. یا روی دکمه «باز کردن ربات در تلگرام» می‌زند (کد خودکار ارسال می‌شود) یا کد ۸ حرفی را دستی در ربات می‌فرستد
۴. صفحه به‌طور خودکار به‌روز می‌شود و اتصال تایید می‌گردد

کد اتصال ۱۵ دقیقه اعتبار دارد، فقط یک بار قابل استفاده است و پس از مصرف باطل می‌شود.

## تنظیمات مدیریتی

در `/admin/settings` بخش «ربات تلگرام»:

| تنظیم | توضیح |
|---|---|
| ربات فعال باشد | خاموش کردن کامل ربات |
| دریافت پیام با ورکر | اگر webhook دارید خاموش کنید |
| اجازه کنترل سرور از تلگرام | اگر نمی‌خواهید کاربران سرور را از تلگرام خاموش کنند، خاموشش کنید |

---

## نکات امنیتی

- هر چت تلگرام فقط به یک حساب پنل وصل می‌شود و برعکس.
- دستورهای کنترلی فقط برای سرورهای همان کاربر کار می‌کنند؛ حتی اگر کسی شناسه سرور دیگری را حدس بزند، رد می‌شود.
- webhook با هدر `X-Telegram-Bot-Api-Secret-Token` و مقایسه زمان‌ثابت اعتبارسنجی می‌شود.
- اگر کاربر ربات را بلاک کند، اتصال به‌طور خودکار غیرفعال می‌شود تا سامانه بی‌جهت تلاش نکند.
- تمام عملیات انجام‌شده از تلگرام در دفتر ممیزی ثبت می‌شود.

---

## عیب‌یابی

**ربات پیام نمی‌دهد**
`npm run telegram` را اجرا کنید. اگر اتصال برقرار نشد، مشکل از دسترسی شبکه به تلگرام است.

**پیام‌ها دو بار می‌آیند**
هم webhook فعال است و هم ورکر. یکی را خاموش کنید.

**کاربر می‌گوید اعلان نمی‌گیرد**
در پنل او بخش اطلاع‌رسانی را بررسی کنید: ممکن است `/mute` زده باشد، ساعات سکوت فعال باشد یا آن دسته رویداد را خاموش کرده باشد.

**«پیام‌های در صف» عدد بزرگی نشان می‌دهد**
ورکر اجرا نمی‌شود یا webhook خطا می‌دهد. لاگ ورکر را ببینید.
