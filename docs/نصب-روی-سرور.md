# نصب روی سرور — از صفر تا صد

راهنمای استقرار پنل روی یک سرور خالی با داکر، برای دامنه `hetzner.pasargadmizban.com`.

فرض‌ها:

- سرور اوبونتو ۲۲.۰۴ یا ۲۴.۰۴ (خارج از ایران، تا به هتزنر و تلگرام دسترسی مستقیم داشته باشد)
- دسترسی root یا کاربر sudo
- دامنه در دست شما

---

## گام ۰ — رکورد DNS

پیش از هر چیز، در پنل DNS دامنه‌تان یک رکورد `A` بسازید:

```
hetzner.pasargadmizban.com  →  آی‌پی سرور
```

چند دقیقه صبر کنید و با `ping hetzner.pasargadmizban.com` مطمئن شوید به سرور می‌رسد.
بدون این، صدور گواهی TLS در گام ۷ شکست می‌خورد.

---

## گام ۱ — آماده‌سازی سرور و فایروال

```bash
apt update && apt upgrade -y
apt install -y ufw curl git nano

ufw allow OpenSSH
ufw allow 80/tcp
ufw allow 443/tcp
ufw enable
```

> پورت ۳۰۰۰ را باز نکنید؛ پنل فقط روی 127.0.0.1 گوش می‌دهد و Nginx جلوی آن می‌نشیند.

---

## گام ۲ — نصب داکر

```bash
curl -fsSL https://get.docker.com | sh
docker --version
docker compose version
```

باید نسخه Docker و Docker Compose چاپ شود.

---

## گام ۳ — انتقال کد به سرور

راه پیشنهادی: کد را روی گیت‌هاب (مخزن خصوصی) بگذارید و روی سرور کلون کنید تا
به‌روزرسانی‌های بعدی فقط یک `git pull` باشد:

```bash
git clone https://github.com/Namesisr/PasargadMizban.git /opt/pasargad
cd /opt/pasargad
```

راه جایگزین (بدون گیت): از ویندوز با scp آپلود کنید. در PowerShell، از داخل پوشه پروژه:

```powershell
scp -r . root@IP-سرور:/opt/pasargad
```

> پوشه‌های `node_modules` و `.next` را لازم نیست ببرید؛ داخل ایمیج ساخته می‌شوند.

---

## گام ۴ — فایل تنظیمات

```bash
cd /opt/pasargad
cp .env.example .env
nano .env
```

این مقادیر را حتماً تنظیم کنید:

```bash
NODE_ENV=production
APP_URL=https://hetzner.pasargadmizban.com

# رمز دیتابیس داخل داکر — docker-compose همین را به Postgres می‌دهد
POSTGRES_PASSWORD=یک-رمز-قوی-برای-دیتابیس

# میزبان دیتابیس در داکر «db» است
DATABASE_URL="postgresql://pasargad:همان-رمز-بالا@db:5432/pasargad_cloud?schema=public"

# دو کلید امنیتی — با دستورهای پایین بسازید
SESSION_SECRET=
ENCRYPTION_KEY=

CRON_SECRET=یک-رشته-تصادفی

# توکن هتزنر را اینجا نگذارید؛ بعداً از پنل در /admin/hetzner اضافه می‌شود
HETZNER_API_TOKEN=

# کد مرچنت واقعی زیبال (مقدار «zibal» یعنی حالت تست)
ZIBAL_MERCHANT=کد-مرچنت-شما
```

ساخت دو کلید امنیتی:

```bash
openssl rand -base64 48        # برای SESSION_SECRET
openssl rand -hex 32           # برای ENCRYPTION_KEY (دقیقاً ۶۴ کاراکتر هگز)
```

> **هشدار:** پس از راه‌اندازی، `ENCRYPTION_KEY` را هرگز عوض نکنید؛ رمز روت سرورها و
> توکن‌های هتزنر با آن رمز شده‌اند.

اختیاری ولی به‌شدت پیشنهادی: `SMTP_*` برای ایمیل، `TELEGRAM_BOT_TOKEN` برای ربات،
و `IRAN_PROBE_URL` و `IRAN_PROBE_SECRET` که در گام ۹ می‌سازیم.

## گام ۵ — بیلد و راه‌اندازی

```bash
cd /opt/pasargad

# ۱) دیتابیس بالا بیاید
docker compose up -d db

# ۲) ایمیج پنل ساخته شود (بار اول چند دقیقه طول می‌کشد)
docker compose build app

# ۳) ساخت جدول‌ها و داده‌های اولیه — فقط بار اول
docker compose run --rm app npm run setup

# ۴) همه سرویس‌ها: وب + ورکر + دیتابیس
docker compose up -d

docker compose ps
```

هر سه سرویس باید `running` باشند. بررسی سریع:

```bash
curl -s http://127.0.0.1:3000 | head -c 200
docker compose logs -f --tail=50 worker
```

ورکر باید پیام «🚀 ورکر پاسارگاد میزبان راه‌اندازی شد» را چاپ کند. بدون ورکر،
صورتحساب ساعتی، بررسی آی‌پی، نرخ خودکار یورو و بقیه کارهای پس‌زمینه انجام نمی‌شوند.

## گام ۶ — Nginx

```bash
apt install -y nginx
nano /etc/nginx/sites-available/pasargad
```

محتوا:

```nginx
server {
    listen 80;
    server_name hetzner.pasargadmizban.com;

    client_max_body_size 10m;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # تعویض آی‌پی تا ۵ دقیقه طول می‌کشد؛ مهلت پیش‌فرض ۶۰ ثانیه آن را می‌بُرد
        proxy_read_timeout 330s;
        proxy_send_timeout 330s;
    }
}
```

فعال‌سازی:

```bash
ln -s /etc/nginx/sites-available/pasargad /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx
```

## گام ۷ — گواهی TLS

```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d hetzner.pasargadmizban.com
```

ایمیل بدهید، شرایط را بپذیرید و گزینه redirect را انتخاب کنید. تمدید خودکار است؛
با `certbot renew --dry-run` امتحانش کنید.

از این لحظه پنل روی `https://hetzner.pasargadmizban.com` بالاست.

## گام ۸ — پیکربندی اولیه پنل

1. `https://hetzner.pasargadmizban.com/register` — ثبت‌نام کنید؛ **نخستین حساب خودکار
   مدیر کل می‌شود**، پس اول از همه خودتان ثبت‌نام کنید.
2. `/admin/hetzner` — توکن‌های Hetzner Cloud را اضافه کنید (Read & Write).
3. `/admin/catalog` — «همگام‌سازی با هتزنر» را بزنید و پلن‌ها و لوکیشن‌های دلخواه را روشن بگذارید.
4. `/admin/pricing` — نرخ یورو و درصد سود؛ یا کارت «نرخ خودکار یورو» را پیکربندی و روشن کنید.
5. در پنل زیبال، آدرس بازگشت را ثبت کنید:
   `https://hetzner.pasargadmizban.com/api/wallet/callback`
6. بررسی سلامت:

```bash
docker compose exec app npm run health
```

## گام ۹ — سرویس آزمایش دسترسی از ایران

این سرویس روی **یکی از سرورهای ایرانی خودتان** اجرا می‌شود تا پنل بفهمد آی‌پی سرور
تازه از داخل ایران باز می‌شود یا نه.

روی سرور ایرانی (اوبونتو/دبیان):

```bash
apt update && apt install -y nodejs
mkdir -p /opt/iran-probe
# فایل scripts/iran-probe-agent.mjs را از پروژه به این مسیر کپی کنید، مثلاً:
scp scripts/iran-probe-agent.mjs root@IP-سرور-ایرانی:/opt/iran-probe/

# یک کلید بسازید و یادداشت کنید
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

سرویس systemd تا همیشه بالا بماند:

```bash
cat > /etc/systemd/system/iran-probe.service << 'EOF'
[Unit]
Description=Pasargad Iran reachability probe
After=network-online.target
Wants=network-online.target

[Service]
Environment=IRAN_PROBE_SECRET=کلیدی-که-ساختید
Environment=PORT=8787
ExecStart=/usr/bin/node /opt/iran-probe/iran-probe-agent.mjs
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable --now iran-probe
curl -s http://127.0.0.1:8787/health
```

در فایروال سرور ایرانی، پورت ۸۷۸۷ را فقط برای آی‌پی سرور پنل باز کنید:

```bash
ufw allow from آی-پی-سرور-پنل to any port 8787 proto tcp
```

سپس روی سرور پنل، در `/opt/pasargad/.env`:

```bash
IRAN_PROBE_URL=http://آی-پی-سرور-ایرانی:8787
IRAN_PROBE_SECRET=همان-کلید
```

و اعمال:

```bash
docker compose up -d --force-recreate app worker
```

وضعیت را در `/admin/ip-health` ببینید؛ باید بگوید «سرویس آزمایش در ایران فعال است».

## گام ۱۰ — به‌روزرسانی‌های بعدی

```bash
cd /opt/pasargad
git pull                                   # یا آپلود نسخه تازه
docker compose build app
docker compose run --rm app npm run db:push   # اعمال تغییرات دیتابیس، بدون پاک شدن داده

```

## دستورهای روزمره

| کار | دستور |
| --- | --- |
| وضعیت سرویس‌ها | `docker compose ps` |
| لاگ وب | `docker compose logs -f app` |
| لاگ ورکر | `docker compose logs -f worker` |
| بررسی سلامت | `docker compose exec app npm run health` |
| ری‌استارت | `docker compose restart app worker` |
| بکاپ دیتابیس | `docker compose exec db pg_dump -U pasargad pasargad_cloud > backup-$(date +%F).sql` |
| بازگردانی بکاپ | `cat backup.sql \| docker compose exec -T db psql -U pasargad pasargad_cloud` |

بکاپ شبانه خودکار:

```bash
crontab -e
# این خط را اضافه کنید (هر شب ۳:۳۰، نگهداری ۱۴ نسخه آخر):
30 3 * * * cd /opt/pasargad && docker compose exec -T db pg_dump -U pasargad pasargad_cloud | gzip > /root/db-$(date +\%F).sql.gz && ls -t /root/db-*.sql.gz | tail -n +15 | xargs -r rm
```

## عیب‌یابی سریع

| نشانه | علت و درمان |
| --- | --- |
| صفحه ۵۰۲ از Nginx | `docker compose ps` — سرویس app پایین است؛ لاگش را ببینید |
| «حساب هتزنر ثبت نشده» | از `/admin/hetzner` توکن اضافه کنید |
| قیمت‌ها صفر یا خالی | کاتالوگ را همگام‌سازی و نرخ یورو را تنظیم کنید |
| هزینه ساعتی کسر نمی‌شود | ورکر پایین است — `docker compose logs worker` |
| پرداخت برنمی‌گردد | آدرس بازگشت در پنل زیبال و `APP_URL` را چک کنید |
| تعویض آی‌پی وسط کار قطع می‌شود | `proxy_read_timeout` در Nginx را مطابق گام ۶ بگذارید |
