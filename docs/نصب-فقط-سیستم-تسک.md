# نصب فقط سیستم تسک — از صفر تا صد

این راهنما فقط **میز کار تسک‌ها** (پنل کارفرما و پنل برنامه‌نویس) را بالا می‌آورد. هتزنر، فروش
سرور، کیف پول، درگاه پرداخت و پنل مدیریت سایت **خاموش و پنهان** هستند و هیچ تنظیمی برایشان لازم
نیست. همه این‌ها با یک خط در فایل `.env` انجام می‌شود:

```bash
APP_MODE=tasks
```

مثال‌ها برای دامنه `tasks.pasargadmizban.com` نوشته شده‌اند؛ هر دامنه یا زیردامنه‌ای می‌خواهید
جایگزین کنید.

فرض‌ها:

- سرور اوبونتو ۲۲.۰۴ یا ۲۴.۰۴ (سرور ایرانی هم کار می‌کند، ولی برای اعلان تلگرام باید به
  `api.telegram.org` دسترسی داشته باشد)
- دسترسی root
- یک دامنه یا زیردامنه

> **اگر روی همان سروری نصب می‌کنید که سایت اصلی‌تان رویش است**، در گام ۵ مقدار `APP_PORT=3100`
> را هم بگذارید و در گام ۷ به جای `3000` از `3100` استفاده کنید تا با سایت اصلی تداخل نکند.
> گام‌های ۲ و ۳ را هم اگر قبلاً انجام داده‌اید رد کنید.

---

## گام ۱ — رکورد DNS

در پنل DNS دامنه یک رکورد `A` بسازید:

```
tasks.pasargadmizban.com  →  آی‌پی سرور
```

چند دقیقه صبر کنید تا `ping tasks.pasargadmizban.com` آی‌پی سرور را برگرداند.

## گام ۴ — آوردن کد روی سرور

مخزن خصوصی است، پس یک توکن فقط‌خواندنی لازم است: در گیت‌هاب **Settings ← Developer settings ←
Personal access tokens ← Fine-grained**، فقط به مخزن `pasargadmizban` با سطح **Contents:
Read-only** دسترسی بدهید.

```bash
git clone https://توکن-شما@github.com/namesissr/pasargadmizban.git /opt/tasks
cd /opt/tasks
```

## گام ۵ — فایل تنظیمات

دو کلید امنیتی بسازید و جای امنی یادداشت کنید:

```bash
openssl rand -base64 48   # برای SESSION_SECRET
openssl rand -hex 32      # برای ENCRYPTION_KEY
```

فایل تنظیمات را بسازید:

```bash
nano .env
```

و فقط همین‌ها را بنویسید (بقیه لازم نیست):

```bash
NODE_ENV=production
APP_MODE=tasks
APP_NAME="میز کار پاسارگاد میزبان"
APP_URL=https://tasks.pasargadmizban.com

POSTGRES_PASSWORD=یک-رمز-قوی
DATABASE_URL="postgresql://pasargad:همان-رمز-بالا@db:5432/pasargad_cloud?schema=public"

SESSION_SECRET=کلید-اول
ENCRYPTION_KEY=کلید-دوم

# اعلان تلگرام — توکن ربات را از @BotFather بگیرید (به‌شدت پیشنهادی)
TELEGRAM_BOT_TOKEN=

# پیامک کاوه‌نگار — هر رویداد تسک به موبایل اعضا پیامک می‌شود
SMS_PROVIDER=kavenegar
SMS_API_KEY=کلید-API-از-پنل-کاوه‌نگار
SMS_SENDER=شماره-خط-ارسال

# ایمیل (اختیاری) — برای ارسال گزارش صبحگاهی و رویدادهای مهم با ایمیل
SMTP_HOST=
SMTP_PORT=587
SMTP_SECURE=false
SMTP_USER=
SMTP_PASS=
SMTP_FROM=

# فقط اگر روی همان سرور سایت اصلی نصب می‌کنید:
# APP_PORT=3100
```

> بدون تلگرام، پیامک و ایمیل هم سیستم کار می‌کند، ولی اعلان‌ها فقط داخل پنل دیده می‌شوند و بخش «هیچ
> کاری فراموش نشود» نصفه می‌ماند. دست‌کم پیامک یا ربات تلگرام را راه بیندازید.

> **کلید و خط کاوه‌نگار:** در پنل کاوه‌نگار از منوی **تنظیمات ← کلید API** کلید را کپی کنید و از بخش
> **خطوط من** شماره خط ارسال را بردارید. برای اعلان‌های متنی آزاد، خط اختصاصی مطمئن‌تر است؛ اگر پیامک
> آزمایشی خطا داد، متن خطا را در گام ۹ می‌بینید.

## گام ۶ — ساخت و اجرا

```bash
cd /opt/tasks
docker compose up -d db
docker compose build app
docker compose run --rm app npm run setup   # فقط بار اول: ساخت جدول‌ها
docker compose up -d
docker compose ps
```

هر سه سرویس (`db`، `app`، `worker`) باید `running` باشند. ورکر را بررسی کنید:

```bash
docker compose logs --tail=20 worker
```

باید این را ببینید: «ورکر در حالت «فقط سیستم تسک» راه‌اندازی شد». یادآوری‌ها و گزارش صبحگاهی را
همین ورکر می‌فرستد.

---

## گام ۷ — Nginx

```bash
apt install -y nginx
nano /etc/nginx/sites-available/tasks
```

محتوا (اگر `APP_PORT=3100` گذاشتید، `3000` را به `3100` تغییر دهید):

```nginx
server {
    listen 80;
    server_name tasks.pasargadmizban.com;

    # پیوست تسک‌ها تا ۱۰ مگابایت است
    client_max_body_size 25m;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

فعال‌سازی:

```bash
ln -s /etc/nginx/sites-available/tasks /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx
```

> اگر Nginx روی این سرور تازه نصب شده و سایت دیگری ندارد، `rm -f /etc/nginx/sites-enabled/default`
> را هم بزنید. اگر سایت اصلی‌تان روی همین سرور است، **این خط را نزنید**.

## گام ۸ — گواهی HTTPS

```bash
certbot --nginx -d tasks.pasargadmizban.com
```

گزینه redirect را انتخاب کنید. تمدید خودکار است.

## گام ۹ — راه‌اندازی تیم

1. **اول خودتان** در `https://tasks.pasargadmizban.com/register` ثبت‌نام کنید. نخستین حساب خودکار
   مدیر (کارفرمای اصلی) می‌شود.
2. پیوند ثبت‌نام را برای شریکتان و برنامه‌نویس‌ها بفرستید. هر کس ثبت‌نام کند صفحه «منتظر تعیین
   نقش» را می‌بیند و به شما اعلان می‌رسد.
3. در پنل کارفرما به **اعضای تیم و نقش‌ها** بروید و نقش هر نفر را تعیین کنید:
   - **کارفرما** برای شریکتان
   - **برنامه‌نویس** برای برنامه‌نویس‌ها
4. هر نفر از **حساب من و اعلان‌ها** شماره موبایلش را در کارت «پیامک» ذخیره کند و «ارسال پیامک آزمایشی»
   را بزند؛ اگر تلگرام دارید، «اتصال به تلگرام» را هم بزند و در تلگرام Start کند. در صفحه «اعضای تیم»
   کنار نام هر نفر دیده می‌شود پیامکش فعال است یا هنوز شماره ثبت نکرده.

از این لحظه سیستم آماده است: تسک ثبت کنید، برنامه‌نویس در `/dev` آن را می‌بیند.

> اگر کسی از تیم رفت، از همان صفحه «اعضای تیم» حسابش را **غیرفعال** کنید؛ از همه دستگاه‌ها خارج
> می‌شود و تسک‌های بازش سر جایشان می‌ماند تا به نفر دیگری بسپارید.

## گام ۱۰ — پشتیبان‌گیری شبانه

پیوست‌ها (اسکرین‌شات‌ها) هم داخل دیتابیس‌اند، پس این پشتیبان همه‌چیز را دارد.

```bash
crontab -e
```

این خط را اضافه کنید (هر شب ۳:۳۰، نگهداری ۱۴ نسخه آخر):

```
30 3 * * * cd /opt/tasks && docker compose exec -T db pg_dump -U pasargad pasargad_cloud | gzip > /root/tasks-db-$(date +\%F).sql.gz && ls -t /root/tasks-db-*.sql.gz | tail -n +15 | xargs -r rm
```

## دستورهای روزمره

| کار | دستور |
| --- | --- |
| وضعیت سرویس‌ها | `docker compose ps` |
| لاگ سایت | `docker compose logs -f app` |
| لاگ ورکر (یادآوری‌ها) | `docker compose logs -f worker` |
| ری‌استارت | `docker compose restart app worker` |
| بازگردانی پشتیبان | `gunzip -c فایل.sql.gz \| docker compose exec -T db psql -U pasargad pasargad_cloud` |

## عیب‌یابی

| نشانه | علت و درمان |
| --- | --- |
| خطای ۵۰۲ | `app` پایین است؛ `docker compose logs app` را ببینید |
| بعد از ورود، صفحه «منتظر تعیین نقش» می‌آید | مدیر هنوز در «اعضای تیم» نقش این حساب را تعیین نکرده |
| یادآوری و گزارش صبحگاهی نمی‌رسد | ورکر پایین است، یا تلگرام در «حساب من» وصل نشده |
| پیامک نمی‌رسد | در «حساب من» پیامک آزمایشی بزنید؛ متن خطا علت را می‌گوید. «سرویس پیامک تنظیم نشده» یعنی `SMS_API_KEY` خالی است؛ بعد از پر کردنش `docker compose up -d --force-recreate app worker` |
| خطای کاوه‌نگار ۴۰۳ | کلید API اشتباه کپی شده؛ دوباره از پنل کاوه‌نگار بردارید |
| خطای کاوه‌نگار ۴۱۸ | اعتبار پنل کاوه‌نگار تمام شده؛ شارژ کنید |
| خطای کاوه‌نگار ۴۱۱ یا ۴۱۲ | شماره گیرنده یا خط ارسال (`SMS_SENDER`) نامعتبر است |
| «ربات تلگرام روی سرور تنظیم نشده است» | `TELEGRAM_BOT_TOKEN` را در `.env` بگذارید و `docker compose up -d --force-recreate app worker` |
| اسکرین‌شات بزرگ آپلود نمی‌شود | `client_max_body_size 25m` را در Nginx بررسی کنید |
| `port is already allocated` هنگام اجرا | سایت دیگری روی پورت ۳۰۰۰ است؛ `APP_PORT=3100` در `.env` و همان پورت در Nginx |
