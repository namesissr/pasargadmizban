# فونت تصویرهای وبلاگ

فونت **وزیرمتن** (Vazirmatn، نسخه ۳۳.۰.۳) برای نوشتن متن فارسی روی تصویرهای
کاور و نمودارهای وبلاگ، سمت سرور.

- مجوز: SIL Open Font License 1.1 — متن کامل در `OFL.txt`. استفاده، بازنشر و
  همراه کردن با نرم‌افزار آزاد است.
- منبع: https://github.com/rastikerdar/vazirmatn

چرا فونت سایت (یکان بخ) نه؟ آن فونت فقط به شکل woff2 برای وب در پروژه هست و
مجوزش برای ساختن تصویر سمت سرور روشن نیست. وزیرمتن مجوز آزاد دارد و
حروف‌چینی فارسی‌اش در موتور resvg درست است.
