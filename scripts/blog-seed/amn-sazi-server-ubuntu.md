سرور تازه‌ای که به اینترنت وصل می‌شود، از همان دقیقه اول هدف اسکن‌های خودکار است: ربات‌ها پورت‌ها را می‌زنند و رمزهای رایج را امتحان می‌کنند. خبر خوب اینکه **امن‌سازی سرور اوبونتو** کار پیچیده‌ای نیست؛ ده قدم زیر، بیش از ۹۰ درصد این حمله‌ها را بی‌اثر می‌کند.

## ۱) همه بسته‌ها را به‌روز کنید

```bash
apt update && apt upgrade -y
```

بیشتر رخنه‌ها از آسیب‌پذیری‌های شناخته‌شده و وصله‌شده سوءاستفاده می‌کنند. به‌روزرسانی، ارزان‌ترین کار امنیتی دنیاست.

## ۲) کاربر غیرروت بسازید

کار روزمره با `root` یعنی یک اشتباه تایپی می‌تواند سرور را از بین ببرد:

```bash
adduser pm
usermod -aG sudo pm
```

از این به بعد با کاربر `pm` وارد شوید و برای کارهای مدیریتی `sudo` بزنید.

## ۳) ورود با کلید SSH را فعال و ورود با رمز را ببندید

کلید SSH هم امن‌تر است هم راحت‌تر. مراحلش را کامل در [آموزش اتصال به سرور با SSH](/blog/ettesal-be-server-ba-ssh) نوشته‌ایم. پس از آزمایش موفق کلید، در `/etc/ssh/sshd_config`:

```
PasswordAuthentication no
PermitRootLogin prohibit-password
```

```bash
systemctl restart ssh
```

:::warning پنجره ترمینال را نبندید
تا وقتی در یک پنجره تازه ورود با کلید را آزمایش نکرده‌اید، ترمینال فعلی را ببندید.
:::

## ۴) فایروال را روشن کنید

قاعده ساده: همه چیز بسته، جز آنچه لازم است.

```bash
ufw default deny incoming
ufw default allow outgoing
ufw allow 22/tcp
ufw allow 80,443/tcp
ufw enable
ufw status verbose
```

اگر سرویس دیگری دارید (مثلاً دیتابیس)، آن را فقط برای آی‌پی‌های مشخص باز کنید، نه برای همه.

## ۵) پورت SSH را جابه‌جا کنید (اختیاری)

انتقال SSH به پورتی غیر از ۲۲، حجم زیادی از اسکن‌های خودکار را حذف می‌کند. امنیت واقعی نمی‌آورد ولی لاگ شما را تمیز می‌کند:

```
Port 2222
```

یادتان باشد پورت تازه را در فایروال باز کنید.

## ۶) Fail2ban را نصب کنید

Fail2ban آی‌پی‌هایی که پشت سر هم ورود ناموفق دارند را موقتاً بلاک می‌کند:

```bash
apt install fail2ban -y
systemctl enable --now fail2ban
fail2ban-client status sshd
```

## ۷) به‌روزرسانی‌های امنیتی را خودکار کنید

```bash
apt install unattended-upgrades -y
dpkg-reconfigure --priority=low unattended-upgrades
```

اینطور وصله‌های امنیتی بدون دخالت شما نصب می‌شوند.

## ۸) سرویس‌های بی‌استفاده را خاموش کنید

هر سرویس باز، یک سطح حمله است. ببینید چه چیزی گوش می‌دهد:

```bash
ss -tulpn | grep LISTEN
```

هر چه را نمی‌شناسید یا لازم ندارید، غیرفعال کنید:

```bash
systemctl disable --now نام-سرویس
```

## ۹) گواهی SSL بگیرید

برای هر سایتی که کاربر در آن فرم پر می‌کند، HTTPS اجباری است. با Let's Encrypt رایگان است:

```bash
apt install certbot python3-certbot-nginx -y
certbot --nginx -d example.com -d www.example.com
```

تمدید گواهی خودکار انجام می‌شود. HTTPS یک سیگنال رتبه در گوگل هم هست؛ سایت بدون آن در نتایج ضرر می‌کند.

## ۱۰) بکاپ و اسنپ‌شات را جدی بگیرید

امنیت فقط جلوگیری از نفوذ نیست؛ توان برگشتن هم هست.

| نوع | چه زمانی | چه چیزی را نجات می‌دهد |
| --- | --- | --- |
| اسنپ‌شات دیسک | پیش از هر تغییر مهم | خرابی تنظیمات و ارتقای ناموفق |
| بکاپ خودکار روزانه | هر شب | داده‌های روزمره و دیتابیس |
| نسخه بیرونی | هفتگی | از بین رفتن کل سرور |

:::tip
اسنپ‌شات گرفتن پیش از به‌روزرسانی هسته یا نصب پنل، کم‌هزینه‌ترین بیمه‌ای است که می‌توانید بخرید.
:::

## چک‌لیست ماهانه

- لاگ ورودهای ناموفق را ببینید: `journalctl -u ssh | tail -50`
- کاربران سرور را بازبینی کنید: `cat /etc/passwd | tail`
- فضای دیسک و مصرف منابع را چک کنید: `df -h` و `free -m`
- آخرین اسنپ‌شات را آزمایش کنید (بازگردانی روی یک سرور موقت)
